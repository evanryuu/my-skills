# 手绘插画

可复用的绘制函数：本 skill 目录内的 `brush.js`。

## 何时使用

- 页面头部右侧的主插画（与 48–60px 大标题并排），空状态、引导页、营销落地页。
- 一个页面最多一张。不要用在列表、卡片、按钮等产品 UI 内部。
- 如果项目的设计系统限制手绘插画，使用前先确认页面是否允许这种风格；产品 UI 内的图标继续遵循项目的图标规范。

## 视觉规则

**颜色**
- 只用三种：墨黑 `#111`、白 `#FFFFFF`、一种强调色。
- 强调色只给一个焦点元素（通常是星芒）。强调色由当前项目的配色决定，保持整张插画只用一种强调色。
- 大块暗面（如箱子内部）用实心墨黑，不用灰。不用渐变、不用彩色物件、不用网点。

**线条（核心）**
- 每条线都是填充的笔刷轮廓，不是 `stroke`：两端细（约 30%）、中段粗，宽度随噪声 ±25% 变化，走向有 ≤1px 的轻微漂移。
- 主轮廓线宽 3.6–3.8（240 视图框内）；排线 1.5–2；点缀射线 2.6。
- 每条边单独绘制、单独 seed，转角处线条各自出头 1–4px，不闭合成完美折角。
- 外形保持几何准确（等轴投影 `iso()`），「手绘感」只来自线条本身。

**明暗**
- 暗侧面：白底 + 竖向手绘排线（间距约 7，两端长度随机缩进）。
- 落地影：4–5 笔平行斜排线，放在物体左下方，光源默认右上。
- 不用阴影滤镜、模糊或灰色块面。

**构图**
- 视角：3/4 等轴（30°），物体占视图框约 70%。
- 刻意不对称：同类部件（如四片盖）角度各不相同，相差 8–25°。
- 元素 ≤ 3 类：主体、1 个强调色焦点、2 个空心小点缀。

## 动效规则

- **触发**：悬停开始 / 结束；移开时倒放，可在中途反向（`tween` 从当前进度出发）。
- **时长**：全程约 620ms，按剩余距离缩放；缓动 ease-out cubic。
- **分段**：主体变化（盖片打开）占 0–0.7；焦点元素升起、放大、旋转 90° 占 0.2–1；点缀元素随焦点同时出现。错开 ≥ 0.2，形成先后。
- **Line boil**：悬停期间每 140ms 在 3 组 seed 之间切换，线条轻微「呼吸」；静止时停在第 0 组。必须可关闭（Tweak `lineBoil`）。
- 静止画面本身必须完整好看，动效只是加分。
- 不用弹跳、回弹、视差（遵循设计系统 Motion 规则）。

## 实现步骤

1. 在 DC 逻辑里 `import('./skills/hand-drawn-illustration/brush.js')`（或直接复制函数进类里，避免异步首帧）。
2. 用 `iso(cx, cy)` 定义 3D 顶点，算出各面的 2D 多边形。
3. 从后往前排序绘制：落地影 → 背后部件 → 暗面/内部 → 焦点元素 → 正面 → 前方部件。部件翻过 90° 时切换前后层。
4. 每个面用 `k.poly(pts, '#fff', 3.6, seed)`；暗面先 `k.fill` 再 `k.hatch`。
5. 焦点用 `k.sparkle(cx, cy, r, rot, accent, seed)`，点缀用 `fill: '#fff'` 的小星芒 + `k.rays`。
6. 悬停：`onMouseEnter={() => { tween(this,'x',1); boil(this,'x',true); }}`，离开传 `0 / false`；`componentWillUnmount` 调 `cleanup(this)`。
7. 进度读取：`t = state.xT`，用 `seg(t,a,b)` + `EASE_OUT` 得到每段的 0..1，再 `mix()` 插值角度、位置、尺寸。
8. 在 SVG 上放一个透明全尺寸 `rect` 作为命中区域，避免悬停在线条空隙时闪烁。
9. 暴露 Tweaks：强调色（3 选 1）、`lineBoil` 开关。

## 适合这套风格的主题

可用主题：开箱的纸箱、撕页日历（版本更新，翻开页可写版本号）、信封（订阅确认）、空文件夹（空状态）、放大镜（搜索无结果）、书本（学习 / 帮助中心）。同样遵循「一个主体 + 一个强调色焦点 + 开合动作」。

## 检查清单

- [ ] 只有墨黑、白、一种强调色
- [ ] 所有线都是笔刷填充，两端收细，转角出头
- [ ] 暗面用排线，落地影用斜排线
- [ ] 同类部件角度不对称
- [ ] 动效 ≤ 700ms，可中途反向，无弹跳
- [ ] line boil 只在悬停时运行，可关闭
- [ ] 静止画面独立成立
